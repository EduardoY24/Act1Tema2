# Actividad 1 - Tema 2

Repositorio con ejercicios del Tema 2 de Prog Web.

## Contenido

- `index.html` — menú principal con enlaces a todos los ejercicios.
- `ejercicio1.html` a `ejercicio6.html` — ejercicios de HTML/CSS/JS trabajados en clase.
- `img/` — imágenes usadas por los ejercicios.
- `css/`, `js/` — Estilos y scripts usados por algunos ejercicios.

## Cómo verlo

- Repositorio: https://github.com/EduardoY24/Act1Tema2
- Publicado con GitHub Pages: https://eduardoy24.github.io/Act1Tema2/

## Cómo se hizo

1. Se creó el repositorio público `Act1Tema2` en GitHub.
2. Se subieron los ejercicios ya hechos con `git init`, `git add`, `git commit` y `git push`.
3. Se agregó `index.html` en la raíz como menú de navegación hacia cada ejercicio.
4. Se activó **GitHub Pages** desde Settings luego Pages, publicando desde la rama `main`, carpeta raíz (`/`).
5. Se verificó que la página publicada funcionara correctamente (rutas de imágenes, CSS y JS relativas, sin depender de `localhost`).
